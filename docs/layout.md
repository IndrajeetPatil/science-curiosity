# Book layout

The book uses 160 × 240 mm pages, 12.5-point Marathi body text and generous
space around paragraphs and captions. Tiro Devanagari Marathi provides the body
face; Mukta Bold sets section headings. Included font files keep the layout
consistent across systems.

Typst optimises line breaks for justified body text and ragged captions. Marathi
shaping and ligatures remain intact: the text uses neither letter spacing nor
character-level justification. Typst's widow and orphan prevention stays
enabled.

Chapter openings use a quiet label, a large title and a short accent line.
Section headings use space above and below and stay with the following text.
Figures keep captions with their images and have clearance from body text. The
processor table uses larger text, padded rows and subtle alternating fills.
Figure dimensions and placement are adjusted to avoid stranded headings and
very short final pages. The cover spacing is independent from body typography.
